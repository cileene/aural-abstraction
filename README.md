# aural-abstraction

## Brief
We investigate whether acoustic impulse responses, captured using a custom physical prototype, can be used to infer and abstract spatial characteristics of a room. The resulting parameters are mapped to a visual representation, an aural abstraction, which treats sound as a sensing mechanism for spatial perception. 

## Parts
- Physical prototype
- Embedded programming
- Signal processing / analysis
- Unity / Godot visualization
